Meu primeiro projeto em Java para o GitHub

Este é um jogo simples onde o jogador tenta adivinhar um número secreto entre 1 e 500. A cada palpite, o programa informa se o jogador está "Quente", "Frio", "Pelando", etc., com base na proximidade do número secreto. Quanto mais perto o palpite estiver do número sorteado, maior será a "temperatura". O jogo só acaba quando o jogador acertar o número.

Como rodar o jogo : 

1. Clone o repositório.
2. Navegue até a pasta do projeto.
3. Compile o arquivo Java:
   ```bash
   javac Jogo.java
